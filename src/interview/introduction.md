# 葵花宝典

这里用尽量直白的语言讲清 Java 后端面试知识。每道题先给出可以直接回答面试官的结论，再用生活化例子和代码解释原因。

## 推荐学习顺序

1. 先学 Java 基础，弄懂对象、字符串、异常和泛型。
2. 再学集合，重点掌握 ArrayList、HashMap。
3. 学习并发，理解线程安全、锁、volatile 和 CAS。
4. 学习多线程，掌握线程状态、协作方式和线程池。
5. 最后学习 JVM，建立程序从编译到运行的完整认识。
