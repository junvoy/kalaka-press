## 学习路线

| 顺序 | 章节 | 解决的问题 |
| --- | --- | --- |
| 1 | [Java 基础](./basic) | Java 如何运行，对象、字符串、泛型、反射和注解是什么 |
| 2 | [Java 集合](./collections) | 多个对象怎样保存、查询、排序和安全遍历 |

第一次学习先建立概念之间的因果关系，不必背所有源码细节。做到能解释“为什么存在、怎样工作、在什么条件下失效”，再使用章节末尾的问题复习。

## 并发和多线程为什么分开？

- **并发**重点讲“怎样保证共享数据正确”，包括 JMM、锁、volatile、CAS、AQS、ThreadLocal 和并发容器。
- **多线程**重点讲“怎样管理线程”，包括线程状态、创建方式、上下文切换、线程池和死锁排查。

两者关系很密切，但关注点不同。先理解并发问题，再学习多线程工具，会更容易理解为什么线程池和锁要这样设计。

## Java 核心学完后学什么？

先用 Java 基础、集合和现代 Java 写出清晰的业务代码，再用并发、多线程和 JVM 保证它在压力下正确运行。接下来请进入[第一性原理学习地图](../question)，按通信、状态、分布式协作和工程交付继续学习；需要查具体组件时使用[技术索引](../technology-index)。

初学阶段不用同时记完所有框架细节。每章先找一个小项目或最小代码，验证“问题—约束—机制—边界”能否对应真实行为。

## 理解检查方法

每章至少做到：

1. 能指出现成答案中哪些只是惯例或未经验证的假设。
2. 能列出可验证的基本事实、硬约束和目标不变量。
3. 能从这些事实重新构造核心机制，而不是只列 API。
4. 能用一个代码、源码或业务例子验证或证伪结论。
5. 能说明代价、反例和失败后的观察与恢复方式。
6. 最后用 30 秒与 3 分钟两种长度组织表达。

::: warning 版本提醒
JDK 的具体实现会随版本变化。先讲稳定原理，再说明源码细节适用的 JDK 版本，不要把某个版本的实现说成永久规则。
:::
