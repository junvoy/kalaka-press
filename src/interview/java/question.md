## 并发和多线程为什么分开？

- **并发**重点讲“怎样保证共享数据正确”，包括 JMM、锁、volatile、CAS、AQS、ThreadLocal 和并发容器。
- **多线程**重点讲“怎样管理线程”，包括线程状态、创建方式、上下文切换、线程池和死锁排查。

两者关系很密切，但关注点不同。先理解并发问题，再学习多线程工具，会更容易理解为什么线程池和锁要这样设计。

## 复习方法

每道题至少做到：

1. 用自己的话在 30 秒内说出结论。
2. 能举一个代码或业务例子。
3. 知道一个常见误区。
4. 被追问时能从“是什么”继续讲到“为什么”和“什么时候用”。

::: warning 版本提醒
JDK 的具体实现会随版本变化。面试时先讲稳定原理，再说明源码细节需要结合 JDK 版本，不要把某个版本的实现说成永久规则。
:::
